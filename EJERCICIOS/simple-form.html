🎯 Práctica de Implicit y Explicit Waits

Sección 1: Implicit Wait

Este campo siempre está visible desde el comienzo.

ℹ️ Este campo NO necesita Explicit Wait. El Implicit Wait (10 segundos) es suficiente.

Sección 2: Explicit Wait

Este campo aparece dinámicamente tras 2 segundos de hacer clic.

ℹ️ Este campo necesita Explicit Wait. Aparece después de 2 segundos del clic.

Sección 3: Elementos Ocultos

Estos campos están en el DOM pero no son visibles.

ℹ️ Este campo está en el DOM pero con display:none. Implicit Wait lo puede encontrar.
